Welcome to this hands-on tutorial to get familiar with Enonic. The guide is aimed at people new to Enonic, and takes you step by step through content modelling and accessing content via the GraphQL API.

== Who this tutorial is for

This tutorial is for developers who define content types and build front-ends against Enonic's GraphQL API. It covers content modelling, schema management and the Guillotine API, using the Enonic CLI, Content Studio and a local sandbox. Every chapter builds on the previous one, so you gain understanding incrementally while building a small content model of your own.

It does not cover building pages with the Enonic framework. For that, see the https://developer.enonic.com/docs/intro[Introduction to Enonic] and the https://developer.enonic.com/docs/next.xp[Next.js tutorial]. The https://developer.enonic.com/docs/cms[CMS reference documentation] covers every topic in this tutorial in depth, and is the place to go once you know what you are looking for.

If you have any questions, or just want to get in touch - visit the https://discuss.enonic.com[Forum] or join the https://slack.enonic.com/[Community Slack channel]

Good luck! 🙌

NOTE: *In a hurry?* If you just want to get up and running as fast as possible, check out the https://developer.enonic.com/start[quick start docs] instead 🚀
